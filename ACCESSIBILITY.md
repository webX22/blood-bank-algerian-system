# Accessibility Statement

Rifaq aims to make its donor, recipient, and healthcare-team coordination interface usable by people with different access needs. Accessibility is an ongoing project goal; **the application has not been independently audited and does not claim WCAG conformance**.

## Current experience

- The web portal has responsive layouts intended for desktop and mobile browsers.
- The interface offers Arabic (with right-to-left layout), French, and English.
- Forms use native HTML inputs and controls where implemented.
- Reduced-motion preferences are considered in the current stylesheet.

These implementation details are not proof that all flows work with assistive technology or meet an accessibility standard.

## Known limitations

- No independent screen-reader, keyboard-only, magnification, contrast, or formal WCAG audit has been completed.
- Some interface copy and operational screens may not yet be consistently localized across all three languages.
- Responsive rendering and RTL layout need broader testing on real devices, browsers, and assistive technologies.
- The repository has no defined support matrix or formal accessibility test suite.

## Report an accessibility barrier

Please open a GitHub issue using the accessibility feedback category, or contact the project maintainer through <https://github.com/webX22> if the report contains information you do not want public. Include the affected page/control, browser and assistive technology if known, steps to reproduce, and the expected versus actual result. Do not include personal health information or credentials.

We welcome suggestions, but response and remediation timelines are not guaranteed. This project is not authorized for clinical use; accessibility feedback does not constitute healthcare-system approval.
