# Laravel API

The Laravel 13 API is rooted at `/api/v1`; routes are listed in `routes/api.php`. It uses Sanctum bearer tokens, PostgreSQL-compatible schema migrations, seeded blood reference values, and provisional 58-wilaya labels. Commune-level geographic data is not included.

See the [project README](../README.md) for local setup and [real-world readiness limitations](../docs/REAL_WORLD_READINESS.md) before considering deployment.
